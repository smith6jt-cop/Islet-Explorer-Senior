### Hard-won lessons (the redesign's real findings — do not relearn)
The first redesign (broad = scANVI `predict()` on `identity_panel`, seeded by markers)
produced a **catch-all**: ~28% of cells assigned to lineages whose markers they don't
express (Immune_B 1% marker-concordant, Neural 5%, Immune_T 13%). Four root causes:
1. **Over-inclusive subpanels** — the cell-type panels are feature pools padded with
   cell-cycle/state/housekeeping/cross-lineage genes, so a panel **mean is not an identity
   score** (a proliferating acinar cell scores high on the cell-cycle-padded B panel).
2. **z-standardized scoring is the silent killer** — `_standardize_broad` (column z-score
   per lineage) forces a ~uniform argmax, so rare classes vacuum up marker-negative cells.
   **Use ABSOLUTE mean-expression over SPECIFIC genes, never z-scored.** (Absolute scoring
   over specific panels → 85–98% concordance on major lineages; catch-all collapses.)
3. **Detection runs on `lognorm`, not raw counts** — `detect_count` gates (`log1p(1)`,
   `log1p(3)`) are applied to `normalize_total`'d lognorm, so the effective raw-count floor
   drifts with cell size (a single transcript in a small cell clears a "≥3" gate). And
   **81.5% of nonzero gene-in-cell entries are single transcripts** (median 316/cell).
   **Use a RAW TRANSCRIPT-COUNT FLOOR (counts layer ≥ 2, ideally ≥3) for detection/anchoring.**
4. **scANVI was misused** — per docs.scvi-tools 1.1.0, scANVI is semi-supervised: give it
   CLEAN anchor labels + `'Unknown'` for the rest, and it propagates; it treats labels as
   ground truth (no noise correction). Feeding noisy/complete labels → garbage propagation.
   **Use: clean anchors (specific identity_core) + Unknown + `predict()` fills the Unknowns.**
5. **NO `MARKER_DICT` / `SEED_MARKERS`** (user directive, emphatic). Identity = the
   ontology-derived `identity_core` (now shipped upstream).

## Key architectural decisions (do not regress)

1. **Stage 02 ingests from zarr directly** (no stage 01 dependency).
   Implemented in cell 3 of `02_phenotyping.ipynb`. Stage 01's
   `_preprocessed.h5ad` (~100 GB) is not needed.

2. **Never pass `total_counts` as a scVI continuous covariate** — the NB
   size factor already models depth (double-regressing it was the original
   library-size leak PaCMAP worked around). Which *other* covariates a model
   uses is a per-model choice, not fixed to `cell_area` (see CLAUDE.md #1).

3. **Don't select embedding genes by HVG variance ranking.** HVG
   (`adata.var["highly_variable"]`) is metadata only and never subsets the
   PCA/scVI input; the default set is `panel_for_embedding`, and a purposeful
   lineage-discriminating panel (e.g. `embedding_panel`) is allowed (CLAUDE.md #2).

4. **Squidpy graph stats are run on subsamples** (150k for
   co-occurrence, 200k for Moran's I, 100k for ligrec & Ripley).
   Centrality_scores is currently **skipped entirely** because
   `nx.closeness_centrality` on >100k nodes is days-to-weeks even
   subsampled.

5. **scanpy CPU UMAP, not rapids/cuML.** The cuML UMAP produced
   extreme outliers; scanpy CPU UMAP with `metric='cosine'`,
   `min_dist=0.05`, `spread=2.5`, pinned `random_state=0` is reproducible
   and clean.

6. **`leiden` flavor is `igraph`, `n_iterations=-1`** — much faster
   than leidenalg on 1 M cells.
