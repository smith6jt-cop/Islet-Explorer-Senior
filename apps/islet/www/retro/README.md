# Retro artwork for MultiPlex5000

1950s-promotional artwork in the logo's palette. Nothing in the app references these files yet.
Each one is an SVG (lettering fonts embedded) with a PNG render beside it. The round icons are
512 x 512 on their own cream plate, so they read on the dark and the light theme.

| file | meant for | suggested line |
|---|---|---|
| `state-welcome` | welcome / About | (lettered) |
| `state-nothing-selected` | nothing selected yet | "Pick something and we'll take a look." |
| `state-unavailable` | a value the release records as unavailable | "Unavailable — and that is not a zero." |
| `state-working` | a slow card | "Counting cells. Back in a jiffy." |
| `state-whoops` | an error | "Whoops! Science happened." |
| `please-stand-by` | page or card loading | (lettered) |
| `tab-composition` | composition cards | "Who gets what slice." |
| `tab-trajectory` | trajectory cards | "Where the cells are headed." |
| `tab-statistics` | statistics | "The bell curve. With bell." |
| `tab-spatial` | spatial cards | "You are here." |
| `tab-neighborhoods` | neighbourhood cards | "Meet the neighbours." |
| `tab-crossmodal` | cross-modal cards | "Protein meets gene. A perfect match." |
| `tab-viewer` | image viewer | "Take a closer look." |
| `help-booklet` | help links | "Need a hand?" |
| `stamp-provisional`, `stamp-withheld`, `stamp-not-a-zero`, `stamp-approved` | status marks over a card | (lettered) |
| `divider-atomic` | section rule, 1200 x 60, transparent | |

The logos (`../multiplex5000-*.svg`) and these files are generated by
`apps/islet/design/retro/make_logo.py` and `make_icons.py` (run `python3 make_icons.py <dir>`,
where `<dir>/fonts` holds the two fonts and `<dir>/logo` the scripts; Chrome headless makes the
PNGs). Fonts: Lobster and Bebas Neue, SIL Open Font License.
