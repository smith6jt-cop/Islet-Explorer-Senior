# Remediation specifications — not implemented scientific changes

These items separate demonstrated blockers from proposed scientific work. No
proposal below approves a registry, changes a cutoff, transfers a cell identity,
deploys code or activates a release. The dependency matrix references these IDs.

## P1 — remove biological assumptions through explicit specifications

**CORE-1 — emit resolved parameters at execution boundaries.** The completed
read-only trace accounts for all 572 catalog declarations, all 13 registry tables
(341 rows), 11,218 remaining literal candidates and historical producer snapshots.
It identifies 549 declarations with static reads and 23 without a resolved read in
the inspected sources; eight of those 549 also have 1,710 source/report/receipt-bound
values. Other static dispositions are not observed runtime values;
receipt settings and actually fitted artifacts are separately identified. Build a
resolved-configuration artifact before execution, recording each parameter's
source, consumer, units, fixed/fitted/selection/review role and output columns.
Bind it to input and registry hashes. Acceptance: unused settings and unresolved
defaults are explicit; each executed parameter can be traced to a result.

**CORE-2 — enforce registry/tissue hooks.** At the pinned port, the hook API and
registry checks do not govern `levels`/`identity` execution. Define mandatory
capability checks before constructing reference populations or calling a method.
Output: explicit unsupported-route results and consumer-level contracts. Test
that changing a tissue/registry setting affects the intended execution, and that
missing required biology fails without falling back to pancreas. Do this only
after baseline parity; do not silently change the original method while testing it.
The historical pLN receipt's `protein_cutoff_fraction=0.1` is metadata: the wrapper
does not pass it into the evaluator, which reads `protein_evidence.REQUIRE_MIN`.
The RNA receipt's `pancreas_naming_policy` likewise does not control the hardcoded
`shared_er_exact_v1` worker argument. Matching declarations are not evidence that
configuration governs execution. Bind or explicitly mark these settings as
descriptive, and test that an intentional configuration change reaches the
consumer before claiming dynamic configuration support.

**BIO-1 — specify reference populations by tissue and panel.** Trace hormone-
based references, endocrine/exocrine context, lineage-specific selection,
canaries and validation cutoffs. Supply independent tissue-appropriate reference
definitions with minimum evidence and an unavailable policy. Output: approved
specifications for each tissue/panel, then implementations and versioned validation.
Acceptance: missing hormones/references, inadequate populations and insufficient
signal cannot fabricate negative or positive populations. No CODEX numerical
cutoff transfers to PC67, PC33 or pLN without evidence.

**BIO-2 — replace implicit pancreas context with declared capabilities.** Inputs:
