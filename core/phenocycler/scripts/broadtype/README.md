# `scripts/broadtype/` — the broad-typing bake-off (PhenoCycler)

Protocol: `docs/BROADTYPE_PROTOCOL_2026-09.md` (Sections 0–3 frozen 2026-09-05). Everything here is
development only: writes `data/development/broadtype/`, never the stable `data/{cells,geometry_qc,
redsea,expression}` roots or the historical `data/runs/` tree, and creates no manifest of any kind —
there is no run framework left to write one. Rules: root `CLAUDE.md` — no frequency /
uniformity / disease-ordering tuning; QuPath classes and legacy labels are audit context only;
`object_id` is the join key; a missing measurement is `Unavailable(reason)`; every conclusion reads
"this arm at this configuration on donors 6436 and 6442".

Run from `core/phenocycler/` with `../../.venv/bin/python` unless an arm says otherwise.

## The arm contract

An arm is one module `arms/<name>.py` (name = the arm name with `-` → `_`) that

1. defines `ARM = "<name>"`;
2. defines `run(ctx: arm_base.ArmContext) -> pd.DataFrame` returning `records.CALL_COLUMNS` for EVERY
   `ctx.ids` (labels ∈ `declarations.json["labels"]` ∪ {`Ambiguous`, `Unavailable`}; a reason string
   for every Ambiguous/Unavailable; `score` = the arm's own confidence-like number, NaN allowed);
3. uses ONLY `ctx.X` (aligned values for `ctx.markers`, the declared identity markers minus the
   ablated one) and, for image arms, the qptiff planes of exactly those markers — never a state marker,
   never `cell_region`/`islet_num` (audit columns), never a QuPath class, never another arm's calls;
4. ends with `if __name__ == "__main__": raise SystemExit(arm_base.cli(ARM, run, env=<interpreter or R version>, default_params={...}))`;
5. runs in `.venv`; if the method lives in another environment (`external/.venv-som`,
   `external/.venv-nimbus`, `external/.venv-kronos`, R 4.5.1 `/usr/local/bin/Rscript`), the module
   drives it as a subprocess, exchanging parquet/CSV under `data/development/broadtype/scratch/<arm>/`
   (created, then deleted when done unless `--keep-scratch`);
6. records every parameter in `default_params` and pins every external dependency by commit/version;
7. handles an ablation transparently: `ctx.markers` already lacks the withheld marker; an arm whose
   method cannot run without it writes `Unavailable(reason="ablation_removes_required_input")` for all cells;
8. handles a stochastic method by honouring `ctx.seed`; a deterministic arm ignores it;
9. has a synthetic test `tests/test_arm_<name>.py` (no cohort data) that builds a tiny `ArmContext`
   with planted structure and checks the record shape and that the planted label is recovered;
10. is smoke-tested for real on `--donor 6436 --scope frame` once `frame/cells/donor_id=6436.parquet`
    exists (the frame is built in the background; poll for the file).

State markers are appended AFTER identity by the screen driver via `arm_base.state_columns`; arms do not.

## Driver, verdict, release

`screen.py --donors 6436 6442 --arms ...` runs, per arm and donor on the frame: primary (`ctx.seed` 0),
one ablation per declared marker of every held-out-gated label, 5 replicates (seeds 1–5 for stochastic
arms; 90 % hash subsamples otherwise), then `gate.judge_label` for every declared label, then appends the
state columns; writes `verdict/<arm>/donor_id=<d>.json` and `verdict/summary.{json,md}` and appends the
summary to the protocol's Section 4. `verdict.py` applies the survival rule and the A.3 producer rule.
`release.py --arm <producer>` writes the A.4a release (`release/{release.json,label_space.json,calls/}`)
that `phenocycler.integration.phenospace.load_release` accepts.
