## Protein → RNA join

There is one row per RNA cell that passed QC, i.e. the rows of the rna stage's h5ad.

- **Protein source:** PhenoCycler cells with `qc_analysis_eligible` and a nucleus outline.
- **Transfer:** each PhenoCycler cell contributes in proportion to the area it shares with the Xenium cell, after mapping through the validated transform. The code is shared with `build_joined.py`.
- **Values carried:** `feat__<marker>` (aligned) and `feat__redsea__<marker>` (unaligned).
- **Overlap record:** `overlap_edges.parquet` holds every contributing PhenoCycler UUID and its overlap area. The same edges feed the call transfer later (`lift_calls.transfer_calls`).

## Protein typing: the open item

**Maintainer ruling, 2026-10-18.** The typing problems came from using old, dropped methods. Use the current methods:

- no pooled cutoffs;
- reference levels fitted per donor, i.e. the `typing/subpanel.py` classification for pancreas and `typing/build_pln_immune_pheno.py` for pLN;
- the UniFORM-aligned values **from the full-dataset run already done on the workstation `sn4622120742`**.

### Why the typing attempted here is ruled out

- **The calibration's original in-stage typing produced no calls at all.** It dropped any reference with any weight on a marker failing a pooled cross-donor check (mode SD ≤ 0.10). E-cadherin fails that check and sits in all 37 references, so every cell came out `Unavailable`.
- **`type_protein.py` is the stage this session wrote to replace it, and it is superseded.** It was not committed; a copy is kept at `data/development/sameslide_four/recovery/type_protein_superseded.py`. It applied `audit_unmeasured`'s drop policy but kept the pooled cutoff. Under that cutoff, GCG, Vimentin and CD44 were unusable in pancreas, and CD3e, CD20, CD8, CD68, Iba1 and CD11c in pLN. As a result:
  - no alpha, mesenchymal, T, B, macrophage or DC calls were made;
  - only 47–82 beta cells per donor were called.
- **Do not use `protein/typing_*`.**
- **`calibrate_protein.py` no longer types anything** (its typing block was removed). Its UniFORM across only these four acquisitions is also superseded by the full-dataset run.
